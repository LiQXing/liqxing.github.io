# LiQXing 的个人主页

一个关于好奇心、创意和动手尝试的小小空间。

主页包含个人介绍、来自交流的 AI 印象、企鹅倒立骑单车的 2D 动画作品，以及 GitHub 主页入口。个人印象仅依据最初几次交流，不代表完整的个人经历。

## 文件

- `index.html`：主页内容与插画。
- `style.css`：响应式布局、配色与插画动画。
- `script.js`：作品预览的播放管理。
- `penguin-bicycle.html`：可独立打开的 Canvas 动画。
- `icon.svg`：网站图标。

直接用浏览器打开 `index.html` 即可查看；没有依赖安装和构建步骤。

## GitHub Pages

本项目对应 `LiQXing/liqxing.github.io`。在仓库的 Settings → Pages 中，将 Source 设置为 Deploy from a branch，选择 `main` 分支及 `/ (root)` 并保存。网站地址为 `https://liqxing.github.io/`，生效前请以 GitHub 的部署状态为准。

后续修改主页文字可编辑 `index.html`，修改视觉样式可编辑 `style.css`。推送到 `main` 后，GitHub Pages 会更新网页。
