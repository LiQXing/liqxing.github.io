\(T3\) 题意：\(n\) 种卡片(每种长\(l\)​ 高 \(h\)​ 有 \(num\) 个)塞进 \(k\) 个信封

一种卡片浪费的空间就是它所在信封的面积减去他自己的面积

问浪费的空间最小是多少.

看一眼数据范围

\($N\le 15\)$

可以很快的联想到状压\(DP\)

思考一下推出方程

\(f[i][j]=c1,c2⊆i,c1∩c2=∅,c1⊔c2=imin​(f[c1][j−1]+f[c2][1])\)

				r[i|1<<(j-1)]=max(r[i],b[j]);
				num[i|1<<(j-1)]=num[i]+c[j];
				cost[i|1<<(j-1)]=cost[i]+a[j]*b[j]*c[j];
			}
		} 
	}
