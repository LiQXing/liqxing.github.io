P3045 [USACO12FEB] Cow Coupons G

虽然看起来是一个背包，但是看到 \(m\le10^{14}\) 就应该排除。

考虑到用优惠券一定使价格变低。

所以前 \(k\) 小的 \(c\) 一定是最优的。

如果需要增加奶牛，有两种做法，一种是在剩下的奶牛里面调出 \(p\) 最小的。 一种是在前面找出 \(p\) 与 \(c\) 差值最小的，然后从后面调出 \(c\) 最小的。

所以只用维护3个小根堆就行了。

int n,k,m;
struct node{
	int p,c;
}a[N];
inline bool cmp(node x,node y){
	return x.c<y.c;
}
bool vis[N];
priority_queue<pii,vector<pii>,greater<pii> >q1,q2,q3;
signed main(){
	n=read();k=read();m=read();
	up(i,1,n){
		a[i].p=read();
		a[i].c=read();
	}
	sort(a+1,a+1+n,cmp);
	int now=0;
	up(i,1,k){
		now+=a[i].c;
		if(now>m){
			cout<<i-1;
			return 0;
		}
		q1.push({a[i].p-a[i].c,i});
	}
	up(i,k+1,n){
		q2.push({a[i].c,i});
		q3.push({a[i].p,i});
	}
	int ans=k;
	up(i,k+1,n){
		while(vis[q2.top().second])q2.pop();
		while(vis[q3.top().second])q3.pop();
		int pos2=q2.top().second,pos3=q3.top().second;
		int tmp2=q2.top().first+q1.top().first,tmp3=q3.top().first;
		if(tmp2<tmp3){
			now+=tmp2;
			q1.pop();q2.pop();
			q1.push({a[pos2].p-a[pos2].c,pos2});
			vis[pos2]=1;
		}
		else{
			now+=tmp3;
            q3.pop();
            vis[pos3]=1;
		}
		ans++;
		if(now>m){
            cout<<ans-1<<endl;
            return 0;
        }
	}
	cout<<n;
	return 0;
}

P1484 种树

一个\(O(nk)\) 复杂度的暴力DP是很容易想的。

然而正解却是贪心。

当 \(k=1\) 时，显然是取最大的 \(a[i]\)。 当 \(k=2\) 时，要么取\(a[i]\) 和 \(\max_{j<(i-1)||j>(i+1)}(a[j])\)，要么取 \(a[i-1],a[i+1]\)。

那么我们可以考率，当从优先队列取出了一个点后，我们再往里面加一个点，权值为 \(a[i+1]+a[i-1]-a[i]\)。

int n,k;
pii t;
bool vis[N];
int a[N],l[N],r[N],ans;
priority_queue<pii>q;
signed main(){
	n=read();k=read();
	up(i,1,n){
		a[i]=read();
		q.push({a[i],i});
		l[i]=i-1;r[i]=i+1;
	}
	l[n+1]=n;r[0]=1;
	up(i,1,k){
		while(vis[q.top().second])q.pop();
		t=q.top(); q.pop();
		if(t.first<0) break;
		ans+=t.first;
		int pos=t.second;
		a[pos]=a[l[pos]]+a[r[pos]]-a[pos];
		t.first=a[pos]; 
		vis[l[pos]]=vis[r[pos]]=1;
		l[pos]=l[l[pos]];
		r[pos]=r[r[pos]];
		r[l[pos]]=pos;
		l[r[pos]]=pos; 
		q.push(t);
	}
	cout<<ans;
	return 0;
}

Buy Low Sell High

这道题的反悔操作实现的很巧妙。

具体来说，我们对于每一个形如「在第 \(i\) 天买入，在第 \(j\) 天卖出」的决策，假想出一个价格为 \(val\) 的物品，使得「在第 \(i\) 天买入，在第 \(j\) 天卖出，同时买入这个价格为 \(val\) 的物品，并在第 \(k\) 天卖出」，等价于「在第 \(i\) 天买入，在第 \(k\) 天卖出」。这样，我们选择买入这样一个物品，也就相当于撤销了「在第 \(i\) 天买入，在第\(j\) 天卖出」这个决策，而改为「在第 \(i\) 天买入，在第 \(k\) 天卖出」，反悔操作得以实现。

int n,m,ans;
priority_queue<int,vector<int>,greater<int> >q;
signed main(){
	n=read();
	up(i,1,n){
		int x=read();
		if(!q.empty()&&q.top()<x)ans+=x-q.top(),q.pop(),q.push(x);
		q.push(x);
	}
	cout<<ans;
	return 0;
}

int n;
inline int work(int a[],int b[]){

	return ans;
}

P3162 [CQOI2012] 组装

首先，这是一个二次函数。

在\(x=\dfrac{\sum_{i=1}^{i\le n}x_i}{n}\)​​时取得最小值\(\sum_{i=1}^{i\le n}x_i^2-\dfrac{\sum_{i=1}^{i\le n}x_i}{n}\)。 做到这步，我们就可以获得前40分，只需要枚举每种零件选的生产车间，复杂度是指数级的。考虑贪心优化枚举的过程。

所以对于每一类零件，建立一个坐标轴，将零件画成二次函数的形式，这样对于每一个\(ｘ\)值，我们贪心的选\(ｙ\)值最小的那个零件。这样就能构成一个分段函数，而我们将每一种类的零件所构成的分段函数放在一起（用差分数组维护\(y=ax^2+bx+c\) 中的\(b\)与\(c\)），几个二次函数加一起还是二次函数，虽然分的段特别多，但绝对在我们的承受范围内，然后我们用二次函数求最小值的公式把最小值求出来即可（最小值可以在段外）

struct ST{
    int dp[1][20],pos[N][20];
    inline void build(int l,int r,int arr[]){
       // up(i,l,r)dp[i-l+1][0]=arr[i];
        up(i,l,r)pos[i][0]=i;
        int res=0;
        for(int j=1;(1<<j)<=r-l+1;j++){
            for(int i=l;i+(1<<j)-1<=r;i++){
                int x=pos[i-l+1][j-1],y=pos[i-l+1+(1<<(j-1))][j-1];
                //dp[i-l+1][j]=max(dp[i-l+1][j-1],dp[i-l+1+(1<<(j-1))][j-1]);
                pos[i-l+1][j]=arr[x]>arr[y]?x:y;
            }
        }
    }
    inline int ask(int l,int r){
        int k=log2(r-l+1);
        return max(dp[l][k],dp[r-(1<<k)+1][k]);
    }
    inline int askpos(int l,int r,int arr[]){
        int k=log2(r-l+1);
        int x=pos[l][k],y=pos[r-(1<<k)+1][k];
        return arr[x]>arr[y]?x:y;
    }
}T;
int n,k,l,r;
int a[N],sum[N];
struct node{
    int o,l,r,t;
    inline bool operator <(const node&rhs)const{

直接上结论：

为什么？

当遍历到第 \(i\) 个人的时候

1.

\(\max(a_i​,s_i​)\) 为 \(s_i\)​ 时，显然\(s_i​≥d\)，因为在 \(i\) 之前的人只有两种：

  • \(\max(s_j​,a_j​)​ 时，显然 \(d​。
  • \(\max(s_j​,a_j​)=s_i\)​​​ 时，显然 \(d≤s_i​\)。

所以这种情况的话就能更新答案。

2.

\(\max(a_i​,s_i​\)) 为 \(a_i\)​ 时，用前文的证明方式可得：\(d\le a_i\)​。

此时如果 \(s_i​≥d\) ，显然直接更新答案了，证明同上。

否则不更新答案。显然如果非要让这个人去，至少也要让之前的一个人不去，总答案不变，但 \(d\)​ 不会变得更小，所以最好的策略是不去。

排完序就是一道种树。

priority_queue<pii,vector<pii>,greater<pii> >p;
int n,k,a[N],L[N],R[N],len,vis[N],ans;
signed main(){
	k=read();n=read();
	up(i,1,n)a[i]=read();
	sort(a+1,a+n+1);
	up(i,1,n-1){
		a[i]=a[i+1]-a[i]; 
		p.push({a[i],i});
		L[i]=i-1,R[i]=i+1;
	} 
	a[0]=a[n]=inf;
	len=n;
	while(k--){
		while(!p.empty()&&vis[p.top().second])p.pop();
		int t=p.top().second,v=p.top().first;
		ans+=v;
		p.pop();
		int l=L[t],r=R[t];
		vis[t]=1;
        vis[l]=1;
        vis[r]=1;
		a[++len]=a[r]+a[l]-a[t];
		L[len]=L[l],R[len]=R[r],R[L[l]]=len,L[R[r]]=len;
		p.push({a[len],len});
	}
	cout<<ans;
    return 0;
}

Jeff and Permutation

  • 然后我们考虑对于一组\((i,j),i 会产生逆序对的情况：

    • \(Case1\quad a_i

      那么要产生逆序对只能：(1)让\(a_j\)​取反，\(a_i\)不变，(2)让\(a_i,a_j\)都取反

    • \(Case2\quad a_i>a_j\)

      那么要产生逆序对只能：(1)让\(a_i\),\(a_j\)​都不取反，(2)\(a_i\)不取反，\(a_j\)取反

  • 那么综上两种情况：如果\(a_i\)不选择取反，那么就是第二种情况（后面的数比他小），否则\(a_i\)取反那么就是前面比他小的数都会产生贡献。然后就对左右两边统计比\(a_i\)小的个数取\(\min\)。

   	    x=read(),y=read();

    while(!B.empty()){

            A.pop();
