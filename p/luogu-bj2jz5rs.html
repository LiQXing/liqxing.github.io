\(T2\)

比较显然，首先，考虑\(i>k\)，此时每个点可以选择\(n-k\)种，一共有\(n-k\)个点

所以有\((n-k)^{n-k}\)种情况；

当\(i\le k\)时，

则通过枚举可得情况总数为\(k^{k-1}\)

具体证明：

设与1号点相连的有\(x\)个点

剩下的有\(k-x\)个点

因为这些点需要与\(1\)号点相连，所以我们可以运用\(dp\)的思想，把剩下的点与每一个点y视为一个整体，\(x+1\)个点相连

所以可以推出该式子

inline int ksm(int a,int b){
	int res=1;
	a=a%mod;
	while(b){
		if(b&1)res=(res*a)%mod;
		a=(a*a)%mod;
		b>>=1;
	}
	return res;
}
