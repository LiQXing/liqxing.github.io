## 中国剩余定理

求一个数$x$，它模3余2，模5余3，模7余2,求最小的$x$。

如果能找到三个整数$x_1$,$x_2$,$x_3$,使得

$x_1\equiv 2(\mod 3)\quad x_1\equiv 0(\mod 5)\quad x_1\equiv 0(\mod 7)$

$x_2\equiv 0(\mod 3)\quad x_2\equiv 3(\mod 5)\quad x_2\equiv 0(\mod 7)$

$x_3\equiv 0(\mod 3)\quad x_2\equiv 0(\mod 5)\quad x_3\equiv 2(\mod 7)$

则 $x=x_1+x_2+x_3$。

可以把该问题分解为三个子问题。

对于子问题1，我们可以继续分解。

$y_1\equiv 1(\mod 3)\quad y_1\equiv 0(\mod 5)\quad y_1\equiv 0(\mod 7)$

$x_1=2\times y1$。

如果找到了 $y_1,y_2,y_3$,就可以得出$x=2\times y_1+3\times y_2+2\times y_3$。

下面就以求 $y_1$ 为例。

$y_1=35k$

$35k\equiv 1(\mod 3)$。

$k$ 为 $35$ 在$\mod 3$ 的逆元。

接下来就直接求逆元就行了。

### summary

对于同余方程组。

$\begin{cases}x\equiv a_1(\mod m_1)\\x\equiv a_2(\mod m_2)\\...\\x\equiv a_n(\mod m_n)\end{cases}$

注：$m_1,m_2...,m_n$互质。

有解为

令 $M=m_1m_2..m_n$,$M_i=M/m_i$

$$x\equiv (a_1M_1M_1^{-1}+a_2M_2M_2^{-1}+...+a_nM_nM_n^{-1})(\mod M)$$
```cpp
int n,M=1;//不要忘了
int a[N],m[N];
inline int exgcd(int a,int b,int&x,int&y){
    if(b==0){
        x=1;y=0;
        return a;
    }
    int d=exgcd(b,a%b,y,x);
    y-=a/b*x;
    return d;
}
inline int crt(){
    int ans=0;
    up(i,1,n){
        int Mi=M/m[i],x,y;
        exgcd(Mi,m[i],x,y);
        x=(x%m[i]+m[i])%m[i];
        ans=(ans+a[i]*Mi*x)%M;
    }
    return ans;
}
signed main(){
    n=read();
    up(i,1,n){
        m[i]=read();
        a[i]=read();
        M*=m[i];
    }
    cout<<crt();
    return 0;
}
```
## 扩展中国剩余定理

有一说一，excrt 与 crt 关系不大，一般来说实现 excrt 采用迭代法，即不停的合并两个方程，最后得到答案。

对于两个方程 $x\equiv a_1(\mod m)\quad x\equiv a_2(\mod m)$。

将其转化为不定方程 $x=m_1u+a_1\quad x=m_2v+a_2$。

则有 $m_1u-m_2v=a_2-a_1$。

当 $a_2-a_1$ 不能被 $\gcd(m1,m2)$ 整除时，方程无解。

$$\dfrac{m_1}{\gcd}u-\dfrac{m_2}{\gcd}v=\dfrac{a_2-a_1}{\gcd}$$

由扩欧可以解出方程$\dfrac{m_1}{\gcd}u-\dfrac{m_2}{\gcd}v=1$的一个解$u_0,v_0$。

$u_1=u_0\times \dfrac{a_2-a_1}{\gcd},v_1=v_0\times \dfrac{a_2-a_1}{\gcd}$

方程的同解为 $u=u_1-\dfrac{m_2}{\gcd}t,v=v_1+\dfrac{m_1}{\gcd}t$。

带入前式。

$$x=m_1(u_1-\dfrac{m_2}{\gcd}t)=m_1u_1-\operatorname{lcm}(m_1,m_2)t$$

$$x\equiv m_1u_1(\mod \operatorname{lcm}(m_1,m_2))$$

同理可以继续进行多个柿子的合并。

```cpp
int n,M=1;
int a[N],m[N];
inline int exgcd(int a,int b,i128&x,i128&y){
    if(b==0){
        x=1;y=0;
        return a;
    }
    int d=exgcd(b,a%b,y,x);
    y-=a/b*x;
    return d;
}
inline int excrt(){
    int ans=0;
    int m1=m[1],a1=a[1];
    i128 x,y;
    up(i,2,n){
        int a2=a[i],m2=m[i];
        //a2-a1=m1u-m2v
        int c=((a2-a1)%m2+m2)%m2;
        int d=exgcd(m1,m2,x,y);
        if(c%d!=0)return -1;
        x=(x*c/d)%(m2/d);
        ans=a1+x*m1;
        m1=m2/d*m1;
        ans=(ans%m1+m1)%m1;
        a1=ans;
    }
    return ans;
}
signed main(){
    n=read();
    up(i,1,n){
        m[i]=read();
        a[i]=read();
    }
    cout<<excrt();
    return 0;
}

```
